G-Choco Quant · 所有知识、工具、体系、规范、文件、代码、程序的编号与入口

拖动每行最左侧的 ⠿ 即可移动：落在一行的上沿 / 下沿 = 放到它前面 / 后面，落在文件夹中间 = 放进文件夹。每一步都可撤销（↶ 或 Ctrl / ⌘ + Z）。编号由位置自动生成（顶层从 0 起，其余从 1 起），移动、删除、复制后自动重排。删除文件夹时可选「子项上移一级」——子项自然成为上一层的编号。删除的东西进回收站，可恢复。入口只有三种：网址、上传的文件、暂无；填入后可在入口旁点「修改」更改，每次修改都要二次确认。标「机密」的入口只对 JT、被授权的人和该工段负责人显示。标「仅 JT 可见」的顶层文件夹，连同其中全部内容，只在 JT 打开本页时显示。「隐藏」只影响你自己的浏览器。
